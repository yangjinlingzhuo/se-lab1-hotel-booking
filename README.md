# 酒店预订系统（软件工程课程）

多酒店在线预订系统的需求分析与软件设计材料，覆盖实验一（需求分析）与实验二（软件设计与建模）。项目甲方：符子建（241220165）。

本期范围：顾客查询与预订、酒店房型与逐日库存价格、订单确认/改订/取消、入住退房、统计与日志。不包含在线支付、第三方平台、会员积分、智能门锁、动态定价和具体房间号分配。
